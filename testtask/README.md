# Hose

Тестовое задание: управляемый 3D-персонаж в Cocos Creator, который стреляет жидкостью как из шланга.

Cocos Creator 3.8.8, сцена `assets/scenes/main.scene`.

## Управление

| | |
|---|---|
| WASD / стрелки | движение |
| Shift | бег |
| Space | прыжок |
| ЛКМ (удерживать) | струя |
| Колесо мыши | давление |

## Что сделано

- Персонаж на `RigidBody` + `CapsuleCollider`, движение относительно камеры, процедурная анимация ходьбы, прыжка и отдачи.
- Струя считается как набор частиц с баллистикой. По цепочке частиц каждый кадр строится трубчатый меш, поэтому струя гнётся, когда персонаж поворачивается, и рвётся, когда отпускаешь кнопку.
- Угол наклона шланга подбирается так, чтобы струя попадала в точку под курсором с учётом текущего давления. Если цель дальше максимальной дальности, вода просто не долетает.
- Каждая частица делает raycast по пути, при попадании — брызги, лужи на полу, импульс динамическим телам. Ящики и бочки темнеют, когда намокают, и потом высыхают.
- Четыре костра: если поливать их достаточно долго, гаснут, без воды разгораются обратно. Когда потушены все — через несколько секунд загораются снова.
- Шейдер воды `assets/effects/liquid.effect`: френель, блик от основного источника, бегущие по струе полосы. Тот же эффект с дефайнами используется для капель и луж.

## Структура

```
assets/scripts
  camera/   FollowCamera
  player/   PlayerInput, PlayerAim, PlayerController, CharacterRig, HoseGun, HoseLine
  liquid/   LiquidStream, LiquidSpray, PuddleField, LiquidReceiver
  world/    Wettable, FireSpot, FireDirector
  render/   DynamicMeshBuffer, TubeMesher, BillboardBatch, ParticlePool
  ui/       Hud
```

`render/` — небольшие обёртки над динамическим мешем движка (`utils.MeshUtils.createDynamicMesh`), на них построены струя, брызги, лужи, шланг и огонь.

Нужен 3D-физический движок Bullet (по умолчанию в проекте).
